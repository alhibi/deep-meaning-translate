# خطة إضافة المعجم المصغّر

## النتيجة
- زر معجم صغير في شريط أدوات الترجمة، يظهر فقط عندما يوجد نص صالح للبحث.
- نافذة معجمية مصغّرة وهادئة تعرض ترجمة النموذج، المعاني الشائعة، نوع الكلمة، الصيغ، والمترادفات.
- ترتيب المعاني آلياً بحسب سياق الترجمة والشيوع، دون تأخير الترجمة المباشرة أو تغيير واجهتها الأساسية.

## التنفيذ
1. توسيع بنية نتيجة المعجم لتشمل الصيغ والمترادفات ودرجة الشيوع، مع تنقية صارمة لأي نتيجة ناقصة.
2. تطوير طلب المعجم المستقل ليستخدم الكلمة الأصلية وترجمة النموذج كسياق لترتيب المعنى الأنسب، مع تخزين مؤقت ومنع النتائج القديمة.
3. إضافة زر المعجم إلى أدوات النتيجة وفتح نافذة مصغّرة مناسبة للهاتف، مع دعم RTL والإغلاق بالنقر خارجها وEscape وزر الرجوع.
4. نقل العرض المعجمي الحالي إلى النافذة الجديدة كي لا يطيل الصفحة أو يؤثر على موضع الترجمة.
5. إضافة تغطية للعربية والألمانية واللهجات العربية عبر تعليمات معجمية موسعة ومعالجة الصيغ الكتابية واللهجية، مع إبقاء الترجمة الأساسية مستقلة تماماً.
6. إضافة اختبارات للبنية، الترتيب، الزر، النافذة، الصيغ، المترادفات، ومنع أي تعطل أو تراجع في الترجمة.

## تفاصيل تقنية
- ستبقى بيانات المعجم ناتجة من النموذج الحالي ومخزنة مؤقتاً، وليس من قائمة كلمات صغيرة ثابتة؛ وهذا يمنح تغطية واسعة للألمانية والعربية واللهجات بلا تنزيل قاعدة ضخمة على الهاتف.
- لا يُرسل طلب المعجم إلا بعد استقرار الترجمة، ويُلغى منطقياً إذا تغيّر النص، لذلك لا ينافس البث المباشر.
- تُستخدم ترجمة النموذج الحالية كإشارة سياقية لاختيار المعنى الأكثر شيوعاً والأنسب أولاً.

## التحقق
- اختبارات الوحدات والتفاعل كاملة.
- فحص الهاتف: فتح/إغلاق النافذة، عدم تداخل النص، اتجاه العربية، وعدم ظهور زر غير مفيد.
- فحص الترجمة المباشرة والمعجم مع كلمات عربية وألمانية ولهجية، ثم التأكد من سلامة البناء.
