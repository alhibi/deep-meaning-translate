# مراجعة مربع المصدر والترجمة — ١٧ نوفمبر ٢٠٢٦

**النطاق:** الإدخال والتحرير، حياة الطلب والنتيجة، التخطيط والتمرير، الاتجاهات، الإتاحة، حفظ المسودة واستعادتها. لم تتغير هوية التطبيق، المطالبات اللغوية، النماذج، حدود التوليد أو مخازن المستخدم.

**تصنيف الدليل:** VERIFIED يعني فحص المصدر أو اختباراً منفذاً، وOBSERVED يعني سلوكاً شوهد في Chromium. لا تعني هذه المراجعة اختبار جميع الهواتف أو قياس جودة الترجمة اللغوية.

## ١. التشريح والمسار الفعلي

المسار الآن:

1. `ComposerField.tsx`: حقل النظام الأصلي يملك المؤشر والتحديد والتراجع والتمرير؛ React يعكس قيمته. لا يوجد مؤقّت استطلاع أو تعديل للارتفاع مع كل ضغطة.
2. `routes/index.tsx`: يملك المسودة والزوج والأسلوب، ويربط اللصق والإملاء والحفظ بالمترجم.
3. `useTranslator.ts`: يعرّف هوية الطلب من النص المطبّع والمصدر والهدف والأسلوب واللهجة والنموذج، ويملك الجدولة والإلغاء والبث والنتيجة النهائية.
4. `StreamingText.tsx` و`ResultPanel.tsx`: يعرضان الكلمات والانتظار والفشل والأزرار؛ البث ليس إعلاناً مستمراً لقارئ الشاشة.
5. الحفظ يربط المسودة **بنتيجة نهائية تخص هويتها الحالية فقط**؛ أثناء التعديل تُحفظ المسودة و`result: null`، لا إجابة النص السابق.

فصلت هوية القراءة المعروضة عن هوية المسودة المطلوبة. يمكن إبقاء الترجمة السابقة مقروءة أثناء الانتظار، لكن ذلك لا يمنحها صلاحية النسخ أو الاستماع أو الحفظ أو الإثراء للنص الجديد.

## ٣. قرار التخطيط: الاستقرار أولاً

عند بدء العمل كان التنفيذ والاختبار يستخدمان سطرين، وسطرًا ونصفًا عند ظهور لوحة المفاتيح، بينما وثيقة التصميم و`AGENTS.md` يصفان ثلاثة أسطر وسطرين. وُحّد السلوك عمداً على **ثلاثة أسطر كاملة، وسطرين كاملين عند لوحة المفاتيح**، مع ارتفاع سطر واحد للخطين. الاختبار لا يكتفي بأن يكون الارتفاع «ثابتاً»؛ يتحقق من عدد الأسطر ومن 120px على الشاشة المختبرة.

لم أُعد صندوق القياس المتكرر أو `ResizeObserver` أو تحريك `height/min-height` مع الكتابة. النص الطويل يمرّر داخل المصدر، والجواب الطويل يوسّع مساحة العمل دون قصه. الجواب القصير يستخدم المساحة المتاحة وشريط عملياته في أسفلها. بقيت الألوان والخطوط والسّمات الثلاث وإيماءة وصول الكلمات من هوية التطبيق، لكن دون إعادة تحجيم الفقرة عند الاستقرار.

## ٤. الاختبار المنفذ وحدوده

### اختبارات محلية

- `npm run verify`: نجح على المصدر النهائي — الأنواع، ESLint بصفر تحذيرات، **511 اختبارًا ناجحًا و4 متخطاة في 78 ملفًا**، وتباين **51/51** وروابط الوثائق. التغطية الفعلية: statements/branches/functions/lines = **52.74/44.90/45.72/55.19%**، أعلى من الحدود المفروضة؛ ليست نسبة إتقان للمنتج.
- تشمل الانحدارات: تغيّر المصدر/الهدف/الأسلوب/اللهجة/النموذج، التأخير والإلغاء والتراجع إلى الأصل، إعادة المحاولة والمهلة، وقف IME، ملكية الجلسة، الترقية من قراءة حية إلى نهائية، النسخ وإيقاف القراءة الصوتية عند تعديل المصدر، حد النص واتجاهه، وفقرات الإملاء، وإيقاف مؤشرات البث عند انقطاع الاتصال وتجاهل الأجزاء المتأخرة وإبطال الطلب عند مغادرة المترجم.
- `npm run build` و`npm run check:pwa`: نجح بناء الويب وسلامة precache — **56 ملفًا**، منها **54 أصلًا بأسماء مجزّأة**.
- `npm run build:native:web`: بناء غلاف الويب المعبأ وتجهيز **11 مدخلاً** نجح؛ ليس هذا بناء APK أو اختبار جهاز Android.

### المتصفح — Chromium 153 headless

- `field_layout.py`: **٢٣ تحققاً ناجحاً**، منها عدم التراكب والقص وثبات المصدر وعدم استدعاء ResizeObserver.
- `composer_interactions.py`: **٤٤ تحققاً ناجحاً**. حدود الشبكة محاكاة بـReadableStream قابل للتحكم، بينما القارئ والمحلل والجدولة ومكونات العرض حقيقية. شمل أجزاء JSON المتأخرة والبث الأقصر والتحديد واستبدال كلمة والتراجع وسطرًا جديداً ونسخ النتيجة وسجل الجلسة الفعلي وحراسة الحافظة والتركيب وحد الأحرف، وبقاء الإجابة المكتملة قابلة للحفظ محليًا عند انقطاع الشبكة.
- مصفوفة **١٥ تركيبة** من المقاسات 320×568 و390×844 و768×1024 و1440×900 و844×390، والواجهات العربية/الألمانية/الإنجليزية، بتدوير السّمات light/dark/vivid بينها؛ ليست كل التركيبات الـ45 الممكنة. تحقق الاختبار من صنف السمة الحقيقي؛ لم يكتف بكتابة إعداد مفترض.
- محاكاة تغيّر visualViewport، وضوح حقل التحرير مع جواب طويل، والتمييز عن pinch zoom؛ ليست لوحة مفاتيح هاتف فعلية.
- `navigation_stability.py`: **١٥ تحققاً ناجحاً** على خادم التطوير ثم حزمة الإنتاج النهائية؛ استعادة باردة، ذهاب وإياب، دورات سريعة، مستند واحد، خلفية ثابتة وعودة دون طلب ترجمة جديد. أُصلح إعداد الاختبار كي يزرع الجلسة قبل الإقلاع، لا قبل pagehide الذي كان يستبدل fixture، وأصبح رابط الرجوع محدداً بدلاً من محدد يطابق رابطين.
- أُعيد أمرَا `npm run test:e2e:fields` و`npm run test:e2e:nav` على حزمة الإنتاج النهائية المخدومة محليًا: **82 تحققًا ناجحًا إجمالاً** (23 + 44 + 15). مهايئ المعاينة في sandbox يسمح بالتضمين فقط دون تغيير رؤوس الإنتاج أو إضعاف `script-src`. أُصلحت predicates الاختبار كي لا تحتاج `unsafe-eval` بدل تغيير سياسة أمان التطبيق.
- راجعت لقطات الخمول والنتيجة النهائية والتحديث وانقطاع الاتصال بعد انتهاء الحركات الانتقالية المحدودة؛ بقي حقل المصدر في الإحداثيات نفسها، بحجم **311×120px** في عينة 390×844. لقطات `output/final-*.png` وسجلات `output/{verify-final,build-final,fields-e2e,navigation-e2e,native-web-build}.log` محلية ومهملة من Git.
- لا أخطاء تشغيل في رحلات المتصفح المذكورة، ولا طلب ترجمة مدفوع في هذه الاختبارات.

### NOT_VERIFIED

- أجهزة Android فعلية وGboard/Samsung Keyboard، Safari/iOS وFirefox، وقارئ شاشة فعلي.
- جودة أو سرعة مزود ترجمة حقيقي؛ الاختبارات هنا تعزل النقل ولا تدّعي تقييم المعنى أو المزود.
- الميكروفون والتعرّف السحابي الفعليان؛ حفظ الفقرات واختبارات طبقة الإملاء محلية فقط.
- قياس FPS أو الذاكرة أو استهلاك البطارية على عتاد فعلي؛ لا يوجد ادعاء أداء عددي جديد.
- إنتاج APK جديد أو نشر الموقع أو دفع فرع إلى GitHub؛ هذه ليست عمليات نُفذت في هذه المراجعة.

تبقى حدود الاختبار في TD3 وTD12 وTD17 وTD25 من سجل الدين التقني؛ لم تُغلق بتحقق متصفح مكتبي.

## ٥. إعادة التشغيل

```sh
npm ci
npm run dev
# في طرفية أخرى، بعد تثبيت Python Playwright وChromium:
npm run test:e2e:fields
npm run test:e2e:nav
npm run verify
npm run build
npm run check:pwa
```

يمكن تعيين `E2E_URL` لخادم آخر، و`CHROMIUM_PATH` و`CHROMIUM_ARGS` لاستخدام Chromium موجود مسبقاً. لا تحتاج رحلات الحقول أو الملاحة مفتاح مزود. لا تُحفظ نصوص شخصية أو مفاتيح أو لقطات الاختبار المولّدة في Git.
