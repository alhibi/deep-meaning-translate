### Editor follow-up closed 2026-11-17

- **D49 — Draft/result ownership:** obsolete responses and retries could commit during the debounce;
  undo-to-original left the edited request alive; a global length guard hid shorter replacement
  streams; old results could be persisted or acted on for a new source. Immediate generation
  invalidation, exact displayed-key eligibility and inert/disabled result actions fix these paths.
  Paused live text now requests full verification rather than merely changing its provisional flag.
  Connectivity loss cancels unfinished work but preserves a current settled answer's local save and
  session eligibility (unit and browser regression).
- **D50 — Editing stability:** IME Enter/candidate handling, script-dependent geometry, settle font
  jumps, forced bottom scrolling, unbounded animated tokens, destructive pull-clear, clipboard races,
  paragraph-flattening dictation, microphone-start blanking and over-limit swapped drafts are covered
  by the focused editor changes and regressions.
  See [the executed review](2026-11-17-composer-review-ar.md). Physical keyboard/IME, screen-reader and
  hardware-performance coverage remain open under TD12/TD17/TD25, not closed by these checks.

### Content-led canvas follow-up (2026-11-17)

The fixed, screen-filling canvas from D43/D50 held still but was rejected as oversized for short
text. It is replaced by intrinsic CSS-grid source sizing and a naturally sized result. The outer
frame, white focus fill, swap-button decoration and redundant send button are removed. Native
editing/IME and exact translation ownership are unchanged. Two new regression tests failed on the
old fixed-field/decorated-swap behavior; the final gate has 514 passing tests (four still skipped).
The final production Chromium run passed 39 geometry + 76 interaction/matrix + 15 navigation checks.
This closes the specific geometry/polish correction, not real-provider quality/latency or the open
hardware/IME/screen-reader matrix (TD1/TD12/TD17/TD25).

## Rules for this register

- Add an item when a limitation is discovered, even if it will not be fixed now.
- Include evidence and a concrete remediation; "improve quality" is not an item.
- Do not delete a closed item in the same release that closed it; move it to “Closed” with evidence.
- A P1 item blocks a quality claim, not necessarily a release; state that explicitly in release notes.
