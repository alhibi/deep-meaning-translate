## 2. What shipped

- **Cancellation is real end to end**: caller signals reach the transport fetch and body reader, the
  server handler stops before spending, and the enrichment queue aborts the running job before
  releasing the door, with semantic dedupe, priority aging, per-purpose bounds and honest counters.
- **Long-text shadow is bounded and honest**: one plan budget, per-window isolation with an
  `incomplete` mark, cross-window dedupe/order, safe sentence splitting, conservative restores.
- **Model capability evidence**: re-verified docs + live probes; production profiles kept, deeper
  reasoning did not clear the pre-declared bar; ar⇄de corpus and deterministic runner committed.
- **Contextual weather** (opt-in, coarse, server-routed, cached, attributed, no tracking).
- **World cultural discovery** (595 sourced CC0 records, en/ar/de, provenance/licence/attribution,
  lazy bundled corpus, offline, no model calls at browsing time).
- **Documentation, privacy copy and About page updated for the new data flows.**
- **Debt**: TD38/TD40/TD43 closed (D74–D81 evidence); TD39/TD41/TD42 updated; new TD44–TD49 recorded.

## 5. Limitations and NOT_VERIFIED

- Cultural breadth: 595 records from one institution; 14 of 25 taxonomy categories; 10 practice
  categories have no rights-cleared source in this phase and were **not fabricated** (TD44).
  Oceania has one record. All ar/de text is machine-translated institutional metadata, labelled as
  such; there is no human editorial review of the corpus (TD44).
- Weather licensing: Open-Meteo's free tier is non-commercial; geocoding is CC BY-NC per the
  provider's terms; Nominatim is used under its 1 req/s policy. A commercial launch needs a paid
  endpoint or the MET Norway adapter (TD45).
- Physical Android GPS, API 24–30 permission prompts, release signing and the OEM/foldable matrix
  remain NOT_VERIFIED (TD17/TD18/TD48); release signing fails closed.
- Provider uptime/rate behaviour under load, deployed-Worker socket-close propagation, and iOS
  Safari behaviour are NOT_VERIFIED.
- Human review of translation quality (TD1) and live long-text shadow quality (TD41) remain open;
  the evaluation corpus is committed with a human-review slot and a documented protocol.
- Performance on physical hardware/battery is unmeasured; only headless/emulator numbers exist
  (TD25/TD46).

## 7. Performance evidence (A14, appended after the first commit)

A14 built and ran a reproducible harness (scripts/perf, tests/perf) with a mocked provider;
machine output in artifacts/phase2/perf. Gate: 51 PASS / 0 FAIL / 1 NOT_VERIFIED.

- Cold FCP/LCP 36/664 ms (dev server, Chromium, no CPU throttle); typing p95 17.0 ms at 1x and
  43.9 ms at 4x CPU; first word p95 94.8 ms; settle p95 172.1 ms; navigation to stats p50 122.7 ms,
  back p50 473.3 ms with one document.
- Cost per settled sentence: one live prefix stream + one full request + one quiet enrichment;
  identical repeated text 0 requests; reload + same sentence 0 stream requests (device memory).
- A01 verified at the wire: a superseded enrichment request was observed in flight and aborted.
- Bounded stress (300 translate cycles + 200 language/style changes + 50 dialogs, 215.7 s):
  heap 28.26 -> 33.02 MB (+4.76 MB), connected DOM +36, 1 timer / 0 intervals / 0 in-flight after
  quiesce, 0 errors, 0 settle misses. Weather: 1 place + 1 forecast on consent, 0 requests over
  20 s idle, 0 while typing, 1 on manual refresh.
- Finding 1 (fixed in the follow-up commit): discovery was mounting during the first-load window
  because the deferred sentinel margin (600 px) was nearer than the fold on a 390x844 phone
  (8 image requests / 458,988 B before any scroll). The margin is now 160 px; the section stays
  below the fold and mounts as the person approaches it.
- Finding 2 (recorded as TD50, not fixed): 50 culture-detail open/close cycles grow renderer nodes
  2,265 -> 8,926 and add listeners without release after GC + 2.5 s; connected DOM stays flat
  (403 -> 439). A per-navigation retention of similar shape on /stats is pre-existing. This needs a
  product investigation, not a blind workaround; runtime is bounded in the stress run and the
  finding is recorded rather than hidden.
- NOT_VERIFIED: production bundle/FCP on a physical device, battery, IME, iOS/Firefox, unbounded
  sessions, real provider latency/cost. Incident disclosed by A14: one early exploratory probe
  typed a synthetic sentence before the mock guard existed, so up to three short real provider
  calls are SUSPECTED (no user text; all later runs mocked, 0 leak failures).
