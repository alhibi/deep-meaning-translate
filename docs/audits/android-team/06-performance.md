# A6 — Android Performance & Reliability Audit

Status: **Independent audit, evidence-based.** Baseline repo: commit c897209 ('Fix the Android 10 keyboard resize...'), branch main.
Audit date: 2026-11-16, 18:14–18:35 Europe/Berlin. Auditor: perf (subagent A6).

> The working tree was **not clean for the whole audit**. Another agent changed four files during the window (details in 'Audit conditions'). Findings below separate the **committed baseline** from the in-flight fix. Two device builds were installed by the lead while this audit ran (18:16 and 18:20, then the app was uninstalled/reinstalled again at ~18:23), so every device observation is timestamped.

## 1. Verdict

The app's performance architecture is deliberate and mostly sound (all Room/DataStore work on **Dispatchers.IO**, bounded caches, an explicit enrichment queue, no backdrop-filter, reduced-motion handled, gapless PCM player). But the **shipped debug APK was not actually using device persistence at all**: every Capacitor storage call rejected with 'LinguaStore.then() is not implemented on android' (A6-01, P0, observed in logcat). A second first-paint defect (A6-02) made the native build's prerendered shell disagree with the client's first render. Both have **uncommitted local fixes in the tree at the end of this audit** and must be committed, gated and re-verified on the device with a _populated_ archive.

Independently of those two, the Android performance profile has three structural costs that should be fixed before calling a daily-use release stable:

1. **Cold start**: ~720 KB of JS + 79 KB CSS + 51 KB fonts are on the critical path, packaged **deflated** in the APK, and the first translator frame is gated on a serial bridge snapshot (A6-03, A6-04, A6-05).
2. **Per-settle write amplification**: every settled translation rewrites a 120-row / up-to-200 KB translation-memory table and fans out into 4–5 bridge round-trips with a duplicated trim; session persistence rewrites the whole DataStore file on every typing pause (A6-07, A6-08, A6-09, A6-18).
3. **Streaming/render cost**: per-word CSS animations animate filter/letter-spacing/text-shadow per word, and every settled translation auto-prefetches paid cloud voice for every audio piece (A6-10, A6-11, A6-12).

Observed launch time on emulator-5554: **4,961 ms Displayed on first install** (18:17, also the build with A6-01), **1,911 ms Displayed / ~2.6 s to splash removal on the fixed build** (18:20). Emulator GPU is **SwiftShader (software)**, and Gradle/install work overlapped the first measurement, so these are indicative, not a hardware benchmark (see section 6).

## 3. What is already correct (verified, so it is not re-litigated)

- All Room and DataStore calls happen on **Dispatchers.IO** (LinguaStorePlugin.kt:32, 71-81; LinguaRepository.kt:23, 36-257); no SQLite on the main thread.
- The bridge fails closed and calm: plugin load failure returns null, repository errors reject with a non-sensitive message, boot is bounded (platform.ts:30-46, 86-98).
- Caches are bounded: history 2000, saved 300, memory 120 rows/200 KB/30 days, lexicon 40, shadow 30, translator 60, clip cache 40/12 MB.
- The enrichment queue serialises dictionary/shadow/background work with a gap and a hang timeout (enrichment.ts:20-58).
- No backdrop-filter anywhere in src (checked by grep); infinite animations are opacity/transform only (breathe, progress, shimmer) and reduced-motion disables movement (styles.css:672-699).
- Playback: gapless PCM scheduling with underrun recovery, one shared AudioContext, oscillator cleanup on ended (pcmPlayer.ts, feel/sound.ts:88-137).
- Session save has a monotonic seq guard so a stale save cannot overwrite a newer draft (LinguaRepository.kt:76-87).
- Streaming cancels the previous in-flight request, keeps at most one lingering prefix stream, and dedupes committed keys (useTranslator.ts:202-260, 452-471); retry is bounded to one attempt and never interrupts live typing with a rate message.
- Emulator facts used: API 35, WebView 124.0.6367.219, GPU SwiftShader (software), animation scales 1.0, app PSS ~100 MB idle, WebViews=1.
